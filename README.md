# MICO 動作訓練場 v0.4

從 v0.3 更新，使用使用者確認的「MICO_揮劍_僅刪除原第4幀.png」作為唯一揮劍圖像來源。原始幀序列 1、2、3、5、6、7、8、9、10，沒有原第 4 幀，沒有重新生成姿勢。

## 使用方式
將 index.html 與 assets/ 放在同一目錄，或上傳 GitHub Pages 根目錄。無外部套件與 API。
- A/D 或左右方向鍵：走路；Shift＋方向鍵：奔跑。
- S 或下方向鍵：蹲下；Space 或上方向鍵：跳躍。
- J：揮劍；K：技能；Esc：暫停。手機使用虛擬按鈕。

## 修改
- 原圖 9 幀逐一去背、保留原始像素及姿勢，以 330×260 的透明圖及共同地面錨點輸出。站立設計高度約 127.2px，不逐幀拉伸。
- 待機、揮劍及技能改用全身圖，揮劍 0.80 秒。保留原圖的部分劍光，去除場景和地面火花。攻擊期間方向鎖定，命中時機與主斬幀對齊。左向以水平鏡像呈現。
- 保留 v0.3 的場景、操作方式、移動速度（220/390 px/s）、非攻擊關節動畫、跳躍及寶石玩法。

## 驗證與限制
以 Chromium 載入單檔 HTML 內容實測全部 9 幀、左轉攻擊、木樁受擊、跳躍、蹲下和手機模擬點擊。瀏覽器環境禁止直接導覽本機檔案與 localhost，未實測 GitHub 部署。分檔專案的圖片存在性與單檔內嵌圖片一致性已靜態檢查。
原圖第 2、3 幀長劍不清楚，沿用原圖；沒有自行補畫。因原圖有場景，去背邊界及局部劍光可能有瑕疵。走路、奔跑、蹲下及跳躍仍使用舊分件素材，與新揮劍素材間可能有外觀差異。未實測實體手機。
