# MICO 動作訓練場 v0.3

以 v0.2 為基礎修正。將 index.html 與 assets/ 放在同一目錄，開啟網頁或上傳 GitHub Pages 根目錄。無外部依賴。

## 操作
- A/D 或左右方向鍵：移動；Shift＋方向鍵：奔跑。
- S 或下方向鍵：蹲下；Space 或上方向鍵：跳躍。
- J：揮劍；K：技能；Esc：暫停。手機可使用畫面按鈕。

## v0.3
- 保留人物設計高度 127.2px 與原有場景。
- 重新切分近側上臂、校正肩關節位置、用同一肩甲覆蓋交界，清除部分藍色背景殘留。
- 重新設計舉劍、頭頂蓄力、向前下斬、收刀等連續姿勢，手與劍共用握點；劍光取自刀尖運動軌跡。
- 走路 145→220 px/s，奔跑 260→390 px/s；步幅、步頻與加速同步調整。
- Chromium 實測速度、木樁受擊、跳躍落地、蹲下、左轉。測試結果見 TESTS.json。逐相位揮刀檢查另行進行。

## 限制
仍為 2D 圖片分件動畫，不是 3D 蒙皮模型。肩甲固定在軀幹，極端姿勢仍可能有局部遮擋，攻擊命中仍以簡化距離判定。未驗證實體手機、Safari，未上傳 GitHub。
