# MICO 動作訓練場 v0.2

可離線執行的 2D 關節動畫測試版。將 `index.html` 和 `assets/` 放在同一目錄，使用瀏覽器開啟；也可以直接上傳到 GitHub Pages 的儲存庫根目錄。本版本不需 npm、CDN、外部 API 或後端。

## 操作

| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 左右移動 | A / D 或 ← / → | 左右方向鍵 |
| 蹲下 | S / ↓（按住） | 下方向鍵（按住） |
| 奔跑 | Shift + 移動 | 奔跑 + 方向鍵 |
| 跳躍 | Space / ↑ | 跳躍或上方向鍵 |
| 揮劍 | J | 揮劍 |
| 技能 | K | 技能 |
| 暫停 | Esc | 暫停按鈕 |

## v0.2 變更

- 保留 v0.1 的橫向移動、鏡頭、平台、木樁、寶石及多點觸控機制。
- 角色設計高度 127.2px（v0.1 待機 106px × 1.2），以 1280×720 邏輯畫布為基準；動作時實際輪廓高度依姿勢而變。
- 從較大尺寸的雙耳直立角色圖分離關節紋理，以正向運動學及二連桿逆向運動學計算腿部、手臂、披風等。走路及奔跑使用交替腳步軌跡；每個更新週期重算姿勢，不再使用低解析度分鏡循環。
- 蹲下以降低骨盆、彎曲腿部及調整軀幹角度實現，不壓縮整張人物圖。
- 跳躍增加預備姿勢及落地緩衝，攻擊加入手臂關節與劍的同位置連動。
- 接觸陰影、隨高度變化的投影、草地前景遮擋、石橋紋理及高 DPI 畫布（最高 DPR 2）。

## 驗證與限制

`TESTS.json` 是本次 Chromium 自動化操作測試結果，包含走路、奔跑、轉身、蹲下、跳躍落地、技能耗能、木樁受擊、手機同時方向與跳躍；測試時未記錄 JavaScript pageerror。

目前是以 Canvas 2D 與 JavaScript 製作的分件關節動畫版本，不是 Blender／Three.js 3D 模型，也沒有真實 3D 動態光源。左右方向仍使用鏡像，盔甲及披風為手工分層的圖片紋理，極端姿勢可能有局部重疊或剪裁邊緣；背景為 2D 圖片，尚未製作完整前後景深度。實體手機與 Safari 尚未驗證。執行環境無法下載外部 JS 套件，因此先交付可離線操作的版本。尚未上傳或部署到 GitHub。
